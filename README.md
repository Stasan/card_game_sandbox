# card_game_sandbox

## Description
This repo contain a case study of creating a simplified card game mechanic for an undo move. Several decks are populated based on the config stored in the Resources folder. It's possible to move cards between decks and undo all moves with undo button.
There is a generic app bootstrapper initializing config loading, saving and screen management system. Screen organized following MVP pattern. Addressables used for asset loading


## Requirements
Unity version 2022.3.39f1

## Used assets
https://natomarcacini.itch.io/card-asset-pack


## AI usage

Basically almost all of the code in the repo is generated by ChatGPT 04-mini-high model. Early commits in the repo contain most of the code in the single file to simplify updating the code with ChatGPT canvas output. Later code was iterated to be properly split between folders and namespaces.
Workflow was organized as giving instructions to ChatGPT reviewing output, validating it in unity and given instructions to change approaches, fix bugs. Only few things required manual changes from my side to get proper behavior in runtime. Prefabs structure is based on AI instructions
